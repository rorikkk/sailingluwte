De site publiceren

Wat je in de editor opslaat, is bewaard maar nog niet live. Druk op Publiceren om alles wat je hebt opgeslagen in één keer online te zetten.

Elke publicatie kost 15 Netlify-credits (300 per maand in het gratis abonnement). Sla dus gerust een paar wijzigingen op voordat je publiceert. Terug naar de editor · Deploys bekijken op Netlify

Instellingen

Plak eenmalig de URL van de Netlify build hook. Die wordt alleen in deze browser bewaard, nooit in de code van de website. Je maakt hem aan in Netlify onder Project configuration › Build & deploy › Continuous deployment › Build hooks.
